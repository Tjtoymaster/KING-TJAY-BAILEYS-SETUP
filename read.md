# KING-TJAY BAILEYS

A community-maintained WhatsApp Web library.

### Created by KING TJ

KING-TJAY BAILEYS aims to provide a powerful WhatsApp Web integration library with custom pairing branding and enhanced developer utilities.

## Features

- WhatsApp Web connectivity
- Phone number pairing
- Authentication management
- Message handling
- Group management
- JID and LID support
